# CESHI — AI 智能作业批改系统

一键启动，无需安装任何环境。

## 下载

| 文件 | 说明 |
|------|------|
| [ceshi.zip](https://github.com/1sgsugs/wxzj_test/releases/latest/download/CESHI-AI.zip) | 主程序，解压即用 |
| [dataset-examples.zip](https://github.com/1sgsugs/wxzj_test/releases/latest/download/default.zip) | 示例数据集（可选），包含学生作业样本 |

## 使用步骤

### 1. 解压

将 `ceshi.zip` 解压到任意文件夹。

### 2. 启动

双击 `ceshi.exe`，等待 3-5 秒，浏览器会自动打开。

### 3. 登录

| 用户名 | 密码 |
|--------|------|
| |  |

选择学科（数学 / 语文作文），点击进入系统。

### 4. 批改作业

1. 左侧菜单选择「批量批改」
2. 上传学生作业图片（支持 png / jpg）
3. 点击「开始批量批改」
4. 等待处理完成，查看评分结果和评语

### 5. 查看分析

- **个体分析**：选择学生，查看薄弱点频率和分数趋势
- **班级记录**：查看全班学生成绩和薄弱点统计

## 数据集（可选）

下载 `dataset-examples.zip` 解压后，直接在系统中上传。

图片命名格式：`姓名_班级.png`（如 `张三_九年级2班.png`），系统会自动解析学生信息。

## 教师上传答案标准

进入「教师工具」页面：

1. **上传答案图片**：拍照或扫描标准答案，系统自动提取正确答案和分值
2. **上传题目图片**：拍照或扫描试卷题目，系统自动提取题目文本
3. 上传后评分时自动匹配标准答案，未上传时使用内置规则库评分

## 常见问题

**Q：启动后浏览器没自动打开？**
手动打开浏览器访问 http://127.0.0.1:8010

**Q：关闭窗口后还能用吗？**
关闭命令行窗口即停止服务，重新双击 `ceshi.exe` 即可。

**Q：批改结果保存在哪？**
保存在 `ceshi/storage/` 目录下，按学科和学生分类。
